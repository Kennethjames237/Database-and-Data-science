🌐 About

Welcome to my Database & Data Science Lab Projects repository!

This repository brings together my academic work, laboratory projects, and practical explorations in database technologies and data-driven systems as part of my Master's studies in Computer Engineering at Politecnico di Torino (PoliTO).

My interests span the entire data lifecycle — from database design and efficient data management to data integration, analytical processing, and knowledge discovery.

🧠 Areas of Exploration

🗄️ Database Systems & DBMS Design — Relational data modeling, ER diagrams, normalization, database architecture, and query optimization.
📊 Data Science & Analytics — Data preprocessing, exploratory data analysis, statistical analysis, visualization, and extracting meaningful insights from data.
🔍 Data Mining — Discovering patterns, identifying relationships, exploring datasets, and applying analytical techniques to transform raw data into useful knowledge.
🔄 ETL & Data Warehousing — Extracting, transforming, and loading data; data integration; dimensional modeling; and building analytical data warehouses.
🍃 NoSQL Databases — Exploring non-relational database paradigms, document-oriented storage, flexible schemas, and scalable data management.
💻 Advanced SQL — Complex queries, joins, subqueries, CTEs, window functions, and advanced relational data manipulation.
🎯 My Goal

To strengthen my understanding of modern database architectures and data technologies through hands-on projects, experimentation, and continuous learning — bridging the gap between theoretical concepts and practical applications.
